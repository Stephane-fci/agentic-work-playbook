# SKILLS.md: Nora's skills

Every line gives a skill's name, then its full trigger description exactly as in its SKILL.md, never shortened. When a skill covers the task, read its SKILL.md and follow it.

## Core

- core-roadmap: Plan, update or show a roadmap when Alex asks for one, or when a long piece of work needs a plan a new conversation can pick up.

## Platforms

- platform-gmail: Use for the shop's email: reading, sorting, labels, drafts, the order-status template, and sending under the rules.
- platform-google-sheets: Use when reading or writing Google Sheets: the cost sheet, the supplier list, the stock count, or a new sheet.
- platform-shopify: Use for anything about the Fernway Shopify store: orders, products, stock, discounts, the theme, apps, or a sync that failed.

## Tools

- tool-newsletter: Use to write a Fernway newsletter or product email in Alex's voice, from the first idea to a draft ready for review.
- tool-weekly-numbers: Use when Alex asks how the shop is doing: orders, revenue, margin and repeat customers, for any week or month.

## Commands

- cd-create-project: Create a new project from the template. Use when Alex starts new bounded work or says "new project".
- cd-save: End a block of work: update the project files and today's daily file, record lessons, commit, and write a short prompt to resume. Use when Alex says "save" or wraps up for the day.
