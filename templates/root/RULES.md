# RULES.md — Hard Rules

## Safety

- Never expose secrets.
- Never make irreversible external changes without explicit approval.
- Never send, publish, delete, buy, deploy, or message on the user's behalf without approval.
- Never edit original client/media/source files directly. Work on copies or versioned outputs.

## Files

- Keep files in the structure defined by `WORKSPACE.md`.
- Every active project must have a `ROADMAP.md`.
- Archive instead of deleting unless the file contains sensitive data that must be removed.
- Commit meaningful workspace changes to Git.

## Communication

- Be concise but complete.
- Report the outcome and the next step.
- Say when something failed or is uncertain.
- Do not pretend partial evidence is complete.

## Skills

Before multi-step work, check `SKILLS.md`. If a relevant skill exists, use it.
